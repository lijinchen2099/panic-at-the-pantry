Privacy policy.

Panic at the Pantry is an offline, single-player Mac game. It does not require an account or collect or transmit personal information.

The game has no advertising, analytics SDKs, tracking, cloud saves, subscriptions, or in-app purchases.

Information stored on your Mac

The game saves keyboard bindings, difficulty, sound and fullscreen preferences, boss unlock progress, and best results locally on your Mac. These files are used to restore your settings and progress when you play again. The developer does not receive them.

Local game data remains on your Mac until you remove it. If you need help resetting or finding your saved data, use the support page.

Network and device access

Gameplay does not need an internet connection. The game does not request access to your camera, microphone, contacts, location, or photo library, and does not include third-party advertising or analytics services.

Apple services

Downloads and installation through the Mac App Store are handled by Apple under Apple’s privacy policy. Any diagnostic information you choose to share with Apple is governed by your Apple settings and Apple’s policies.

This website and support requests

This website is hosted on GitHub Pages. We do not add analytics, advertising, tracking pixels, embedded social widgets, or third-party fonts. GitHub may process technical information such as IP addresses and request logs to operate and secure its hosting service. See the GitHub Privacy Statement.

If you choose to open a GitHub Issue for support, GitHub processes the account and message information you submit. Issues are public. Do not include passwords, personal contact information, or other private details. Support messages are used to investigate and respond to your request.

Children’s privacy

The game does not knowingly collect personal information from children or any other players.

Changes and contact

Changes to this policy will be posted here with an updated date. For questions about the game or this policy, contact the developer through GitHub Issues.

隐私政策（简体中文）

Panic at the Pantry 是一款离线单人 Mac 游戏，无需注册账号，不收集或传输个人信息，也不包含广告、分析统计、追踪、云存档、订阅或应用内购买。

Mac App Store 下载和安装由 Apple 依据其隐私政策提供。本网站由 GitHub Pages 托管，未添加分析或追踪工具；GitHub 可能为运行和保护服务处理 IP 地址等技术信息，详情见上文所链接的 GitHub 隐私声明。

如通过 GitHub Issues 寻求支持，你提交的内容将公开显示，请勿包含密码、联系方式或其他私人信息。有关本政策的问题，可通过 GitHub Issues 联系开发者。
